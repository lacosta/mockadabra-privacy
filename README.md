# Mockadabra privacy policy site

Static GitHub Pages site for the Mockadabra Chrome extension's privacy policy.

- `index.html` — the policy
- `styles.css` — the only stylesheet (no JavaScript, no external resources); the current-section highlight in the
  table of contents uses CSS scroll-driven animations and is simply absent in browsers without them
- `fonts/` — self-hosted Bricolage Grotesque, Geist and JetBrains Mono (latin subsets, SIL Open Font License 1.1;
  license texts alongside)
- `mark-64.png` — the Mockadabra brand mark used in the header and footer
- `icon-128.png`, `favicon-32.png` — the extension's public store icon
- `.nojekyll` — serve the files as they are

All paths are relative, so the site works under `/mockadabra-privacy/` on GitHub Pages.
