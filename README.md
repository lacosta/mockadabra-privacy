# Mockadabra privacy policy site

Static GitHub Pages site for the Mockadabra Chrome extension's privacy policy.

- `index.html` — the policy
- `styles.css` — the only stylesheet (no JavaScript, no external resources)
- `icon-128.png`, `favicon-32.png` — the extension's public store icon
- `.nojekyll` — serve the files as they are
